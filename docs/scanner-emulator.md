# スキャナエミュレータ（デバッグ用）

## 概要
5桁の数字 + Enter を送信する別ソフト。  
手動モードと自動モードを提供する。

## 実行方法

```
dotnet run --project .\ScannerEmulator\ScannerEmulator.csproj
```

## 使い方

起動後にモードを選択する。

### 1) 手動モード
1. 5桁を入力  
2. 3秒カウントダウン中にアプリの入力欄へフォーカス  
3. 自動で Enter 送信  
4. 空入力で終了

### 2) 自動モード
1. `ketsuban.txt` を **実行フォルダ** または **カレントフォルダ** に置く  
2. 3秒カウントダウン中にアプリの入力欄へフォーカス  
3. 自動送信開始

送信仕様:
- 範囲: **22001〜26299**
- 欠番: `ketsuban.txt` 記載分は **スキップ**
- 間隔: **100ms**
- 形式: 5桁ゼロ埋め + Enter

停止方法:
- `Ctrl + C`

## ketsuban.txt の形式
以下のような行を解析する。

```
欠番: 26211から26300まで
欠番: 25053
```

## 注意
- **フォーカス中のウィンドウに入力される**。必ず入力欄を選択してから開始する。
- 送信先を指定する機能はない。
